Data Engineering · BI

Car Marketplace Data Pipeline & BI Dashboard

An end-to-end data project built on top of the AI-Powered Car Marketplace. A Python ETL pipeline extracts cars, users and favorites from the app's MySQL database, cleans them with Pandas, validates them for missing IDs, duplicates, invalid values and broken references, and loads them incrementally into a star-schema data warehouse. A Java desktop dashboard then reads from the warehouse to show key metrics, charts, top-favorited cars, rule-based business insights and data quality checks.

Stadium Network Infrastructure Design

Designed a scalable network project for a stadium that has to serve thousands of users at once during events. Critical services like administration, security, ticketing and guest Wi-Fi are separated into their own VLANs, and the routing and IP addressing are planned for growth, redundancy and heavy traffic. The design was created and tested in Cisco Packet Tracer.
